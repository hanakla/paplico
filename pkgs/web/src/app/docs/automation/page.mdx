# オートメーション

40 個のオブジェクトに同じ操作を繰り返すのは、退屈なうえに何個かぬけます。そういう作業をスクリプトに任せてしまおう、というのがオートメーションです。

書くときの言語は **Syrup** といって、Swift によく似た見た目をしています。型があるので、ないプロパティを触ろうとしたり、数値のところに文字列を渡したりすると、実行する前にエディタが赤い線を引いて教えてくれます。

## まずは動かしてみる

選んだオブジェクトに順番で名前を振る、という例がいちばん短いです。

```swift
let selected = paplico.editor.selection
guard selected.count > 0 else { return }

for i in 0..<selected.count {
	selected[i].name = "Object $(i + 1)"
}

print("Renamed $(selected.count) objects")
```

スクリプトから手が届くのは、次の 4 つです。

- **ドキュメント**：レイヤーやアートボード、それぞれのオブジェクトの名前、不透明度、ブレンドモード、位置や回転、表示のオンオフ。テキストなら段落や文字スタイルまで覗けます。
- **選択**：いま選ばれているものを取り出したり、選び直したり、解除したり。
- **ダイアログ**：文字や数字を入力してもらう、はい / いいえを聞く、メッセージを見せる。
- **ファイル**：ドキュメントの隣のフォルダを読み書きする、ユーザーに選んでもらったファイルを扱う、保存先を聞く。

ただし、読めるもの全部が書けるわけではありません。`uid` や `type` はそのオブジェクトが何者かを決めている値なので変えられませんし、`bounds` は形と変形から計算された結果なので、書き込んでも意味がありません。書き換えていいものは [スクリプト API](/docs/automation/api) にまとめてあります。

## 実行中に何が起きているか

スクリプトは、キャンバスとは切り離された場所で動きます。うっかり無限ループを書いてしまっても絵を描く手は止まりませんし、60 秒を超えると自動で打ち切られます。もちろん、パネルの停止ボタンでいつでも止められます。

この場所には、ドキュメントの本物は置いてありません。`paplico.activeDocument` から取り出したオブジェクトは、本物を指す引換券のようなもので、値を書き込むと、その 1 件ずつがアプリ本体へ送られていきます。

送られた変更は、その場では反映されません。いったん全部ためておいて、スクリプトが最後まで走り終わったときに、まとめて適用されます。途中でエラーが出たり、停止ボタンを押したりすると、ためた分は捨てられて、ドキュメントは元のまま残ります。20 個だけ名前が変わった中途半端な状態にはならない、ということです。

適用のしかたは普段の編集と同じなので、気に入らなければ Cmd+Z 一回で戻せます。誰かと共同編集していれば、変更はその人にも届きます。

## スクリプトはどこにあるのか

パネルの左に並んでいるうち、はじめから入っているものが 5 つあります。順番に名前を振る、ランダムに動かす、座標を整数に丸める、選択中のテキストを置換する、位置を入れ替える。どれも編集はできませんが、中身は読めるので、自分で書くときの下敷きに使えます。

自分のスクリプトを保存できるのは、デスクトップ版だけです。ブラウザ版でも組み込みのものを読んだり動かしたりはできますが、追加ボタンが出てきません。ファイルの扱いにも同じ線が引いてあって、なぜそうなっているかは [ファイルアクセス](/docs/automation/filesystem) で説明します。

## Syrup を書くときのコツ

文法はだいたい Swift のとおりです。`let` と `var`、`if let`、`guard ... else`、`for ... in`、`switch`、クロージャ、`struct`、`enum` が使えます。ひとつだけ違うのが文字列の埋め込みで、`\(x)` ではなく `$(x)` と書きます。

関数を呼ぶときは引数にラベルを付けます。`paplico.prompt.string(message: "名前")` のように書くので、あとで読み返したときに、その値が何なのか迷いません。ラベルを覚えていなくても、引数の位置で補完を出せば、まだ埋めていないラベルが上のほうに出てきます。

条件はカンマでつなげられます。取り出しと中身のチェックを 1 行にまとめられるので、入れ子が浅くなります。

```swift
if let text = await paplico.prompt.string(message: "一言どうぞ"), !text.isEmpty {
	await paplico.prompt.alert(message: text)
}
```

`await` を付けるのは、ダイアログとファイルを触るときだけです。どちらも返事が返ってくるのを待つ必要があるからで、ドキュメントを読み書きするだけなら要りません。
