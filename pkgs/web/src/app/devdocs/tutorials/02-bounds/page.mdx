# 第2章: AABB — 図形を「四角い箱」で囲む

## この章でできるようになること

- ベジェ曲線を「ぴったりはまる四角い箱」で囲めるようになる
- なぜ「箱で囲む」と便利なのか、自分の言葉で説明できる
- ベジェ曲線が **制御点の中** にしか出てこない (凸包性質) と知れる

## まずは絵で見てみよう

ぐにゃぐにゃした図形でも、その周りに **「ぴったりサイズの四角い箱」** を描くと、コンピューターがすごく扱いやすくなるよ。この箱のことを **AABB** (Axis-Aligned Bounding Box) って呼ぶよ。**Axis-Aligned** は「軸に揃った」という意味。傾いていない、縦横まっすぐな箱だよ。

AABB は **左上の角 (min)** と **右下の角 (max)** の 2 つの点だけで決まるよ。とっても軽いデータだね。

## どこで使われている？

「画面の外にある絵は描かなくていい」って判断するとき、まず AABB を使って **「この絵は画面に重なってる？」** をざっくりチェックするよ。重なってなければ、複雑な計算をぜんぶスキップできる。これを **viewport カリング** って呼ぶよ。

ほかにも、選択ツールで「マウスがどの絵に当たった？」を調べるときにも、最初の 1 段目の絞り込みは AABB でやるよ。**ざっくり判定 → 細かい判定** という二段構えで速く動かす作戦だよ。

## どうやって動くのか — ステップで見ていこう

ベジェ曲線の AABB を出すには、実は **すごく簡単な方法** があるよ。

### ステップ 1: ベジェ曲線は制御点の中にいる (凸包性質)

ベジェ曲線には不思議なルールがあるよ。曲線本体は、**4 つの制御点を結んだ図形 (凸包) の中に必ず収まる** んだ。これを **凸包性質** って呼ぶよ。

### ステップ 2: 制御点の min と max を取る

これだけで AABB ができるよ。

```
xs = [p0.x, p1.x, p2.x, p3.x]
ys = [p0.y, p1.y, p2.y, p3.y]
min = (min(xs), min(ys))
max = (max(xs), max(ys))
```

### ステップ 3: ぴったりじゃないけどそれで OK?

実はこのやり方、**箱が実際よりちょっと大きめ** になることがあるよ。曲線が p1 や p2 のあたりまで届かないことが多いからね。それでも大丈夫。**「曲線がはみ出さない箱」を素早く作る** のが目的だから、少しゆとりがあっても困らないよ。

ぴったりサイズの箱が欲しいときは、もう一歩進んで「ベジェ曲線の極値 (山と谷)」を計算するんだけど、それは下の折りたたみセクションで。

## 数学のところ（読み飛ばしOK）

<details>
<summary>ぴったりサイズの AABB を作るには…</summary>

3次ベジェ曲線の式は:

```
B(t) = (1−t)³ p0 + 3(1−t)² t p1 + 3(1−t) t² p2 + t³ p3
```

これを `t` で微分して、`B'(t) = 0` となる `t` の場所が「極値 (山と谷)」だよ。`B'(t) = 0` は 2 次方程式になるから、`t` は最大 2 つ求まる。

各成分 (x と y) について 2 つずつ解いて、それぞれの `t` で `B(t)` の点を計算し、その点も min/max の候補に入れれば、**ぴったりサイズの AABB** が作れるよ。

```
B'(t) = 3(1−t)² (p1 − p0) + 6(1−t) t (p2 − p1) + 3 t² (p3 − p2)
      = a t² + b t + c   (a, b, c はそれぞれ x, y 成分で別々)
```

2 次方程式の解の公式で `t` を求めて、`0 ≤ t ≤ 1` の範囲のものだけ採用すれば OK。

</details>

`bezierAABB` を書いてみよう。橙色の点線で AABB が表示されるよ。**正しく書けたら、4 つの制御点をぜんぶ含む四角が出る** はず。曲線をドラッグして動かしてみて、箱がついてくるか試してみよう。
