# 第5章: ベジェ曲線を任意の場所で 2 つに切る (t-splitting)

## この章でできるようになること

- ベジェ曲線を **好きな位置で 2 つに切る** ことができるようになる
- パラメータ **t (0 〜 1)** が「曲線のどこ？」を表すことを理解できる
- **線形補間 (lerp)** が中点取りの一般版だ、と気づける

## どこで使われている？

- **消しゴム**: 線の途中で止まったとき、その曲線を 2 つに切って、要らない部分だけ消す
- **パス編集**: 曲線の途中にアンカーポイント (新しい節) を追加するとき
- **アニメーション**: 線が伸びていくアニメ — t を 0 → 1 と動かして「t までの部分」を表示

Paplico の `splitBezierAtT` も、消しゴムやパス編集ツールから呼ばれているよ。

## どうやって動くのか — ステップで見ていこう

実は、第4章の「中点取り」を **線形補間 (lerp)** に置き換えるだけ。すごく似てるよ。

### ステップ 1: 線形補間 (lerp) って何？

2 つの点 a と b を結んだ線の上で、**a から t の割合だけ進んだ点** を返す関数だよ。

```
lerp(a, b, t) = a + (b - a) * t
             = (1 - t) * a + t * b
```

### ステップ 2: De Casteljau を一般化

第4章でやった中点取りを、ぜんぶ lerp に置き換えるよ。

```
m01    = lerp(p0, p1, t)
m12    = lerp(p1, p2, t)
m23    = lerp(p2, p3, t)
m012   = lerp(m01, m12, t)
m123   = lerp(m12, m23, t)
m0123  = lerp(m012, m123, t)        ← 分割点
```

### ステップ 3: 左右の制御点が一気に手に入る

3 段の lerp が終わると、副産物として **左右の曲線の制御点ぜんぶ** が揃ってる。

```
左の曲線:  [p0,    m01,   m012,  m0123]
右の曲線:  [m0123, m123,  m23,   p3]
```

`m0123` が左の終点 = 右の始点になることに注目。

## 数学のところ（読み飛ばしOK）

<details>
<summary>De Casteljau と Bernstein 多項式</summary>

ベジェ曲線の式は Bernstein 多項式で書けるよ:

```
B(t) = (1-t)³ p0 + 3(1-t)² t p1 + 3(1-t) t² p2 + t³ p3
```

De Casteljau のアルゴリズムは、これを「lerp の繰り返し」で求めている。具体的には、各段階で次数を 1 ずつ下げていく:

```
3次:  p0    p1    p2    p3
2次:  m01   m12   m23
1次:  m012  m123
0次:  m0123  ← 曲線上の点
```

数学的には、これは線形演算なので、結果は同じ。実装としては **Bernstein を直接計算するより数値的に安定** なので、グラフィックスでは De Casteljau がよく使われるよ。

</details>
