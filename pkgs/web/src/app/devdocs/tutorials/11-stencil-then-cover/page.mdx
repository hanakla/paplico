# 第11章: ステンシルを使った塗りつぶし (Stencil-then-Cover)

## この章でできるようになること

- 凹凸のある多角形を、**三角形分割なしで** 塗りつぶせる発想がつかめる
- **重心への三角形ファン** をどう作るかが分かる
- **ステンシルバッファ** が「ぬり絵の透明シール」みたいに使える、と感覚で理解できる

## まずは絵で見てみよう

第10章では多角形を **三角形に分けて** 塗ったよね。今度は **三角形に分けないまま** 塗る別の方法を見てみるよ。これは「ぬり絵の透明シール」を貼り重ねる感じ。

## どこで使われている？

- 自己交差した多角形 (8 の字とか)
- ベジェ曲線で囲まれた図形 (フォントの「あ」とか)
- 穴のあいた図形 (ドーナツとか)

これらは **Ear Clipping だけだと正しく塗れない**。Stencil-then-cover なら、複雑な形でも 1 回でしれっと塗れるよ。

Paplico の path-rendering は、いまはこの方式ではなく **CPU で被覆率を積算する sparse strips** を使っているよ。でも「巻き数が 0 かどうかで内外を決める」という考え方はまったく同じ。ここで身につく感覚はそのまま使えるんだ。

## どうやって動くのか — ステップで見ていこう

### ステップ 1: 重心 c を計算

多角形の **重心** (全頂点の平均) を出すよ。

```
c = (Σ p_i) / N
```

### ステップ 2: 重心を中心に三角形ファンを作る

各辺 `(p_i, p_{i+1})` について、**三角形 `(c, p_i, p_{i+1})`** を作るよ。これが **ファン (扇)** という形。

### ステップ 3: ステンシルに +1 / −1 を貯める (本物のお話)

GPU で各ファン三角形を描くとき、**色は出さずに、ステンシルバッファに数を足し引き** するよ。三角形が **時計回り** なら +1、**反時計回り** なら −1。

凹凸ある多角形でも、**最終的に「内側」のピクセルでは数が ≠ 0**、**「外側」では 0** になるよ。これがマジック。

> [!NOTE]
> ステンシルって、紙のステンシルアートと同じ。マスクが「中」「外」を決めて、塗りはそこを通り抜けるかどうかだけ。

### ステップ 4: BBox を「カバー」して色を流す

最後に、多角形の AABB (第2章！) のサイズの **大きな矩形 (cover quad)** を 1 枚描く。GPU には **「stencil ≠ 0 の場所だけ色を出して」** と頼む。これで塗りつぶしが完成。

### この章で書くもの

ステンシル操作は GPU の細かい設定がいるから、この章ではその一歩手前 ; **重心ファンの三角形を作るところ** だけ自分で書いてみよう。結果は GPU で **そのまま重ねて描画** されるよ。多角形が凸なら綺麗に塗れて、**凹だと変な部分が出る** ;それが「stencil なしの限界」を体感させてくれる。

## 数学のところ（読み飛ばしOK）

<details>
<summary>偶奇規則 vs 非ゼロ規則</summary>

塗りつぶしの判定には 2 種類のルールがあるよ。

- **偶奇規則 (even-odd)**: 巻数の偶奇で判定。`stencil & 1` で「中」を判定 (XOR)
- **非ゼロ規則 (nonzero)**: 巻数 ≠ 0 で「中」と判定。SVG / PDF / Canvas2D のデフォルト

非ゼロ規則は、三角形の **向き** (時計回り or 反時計回り) を考慮する。Paplico の path-rendering はこの非ゼロ規則で、ステンシルの代わりに CPU が巻き数を積分して被覆率にしているよ。

</details>

## 実装してみる

`buildFanTriangles` を書いてみよう。星型の多角形に **重心ファン** を作って、GPU で **半透明で重ね描き** するよ。多角形が凸なら綺麗、凹なら **重なって濃くなる場所** が出るよ ;それがステンシルが必要な理由。
