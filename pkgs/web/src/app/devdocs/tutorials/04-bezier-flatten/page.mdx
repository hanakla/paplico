# 第4章: ベジェ曲線をまっすぐな線に分ける (フラット化)

## この章でできるようになること

- ぐにゃっと曲がった線を、たくさんの **真っ直ぐな線の集まり** に分けられるようになる
- 「曲線が直線で近似できるか」を **弦からの距離** で判定できるようになる
- **De Casteljau 分割** で曲線を半分に切る方法が分かる

## まずは絵で見てみよう

ベジェ曲線をそのまま画面に描くのって、実は意外と大変。コンピューターはまっすぐな線を描くのは得意だから、**曲線を「短い直線の集まり」に分けて** から描くと、すごく扱いやすくなるよ。これを **フラット化 (flattening)** って呼ぶよ。

## どこで使われている？

WebGPU や OpenGL みたいな GPU は、**三角形しか直接描けない** んだ。だから、曲線を画面に出すには、まず曲線を直線にバラして、直線を三角形のリボンで太くして、と段階を踏む必要があるよ。フラット化はその一番最初のステップ。

Paplico でも、ベジェ曲線で描かれたあらゆる図形 (パス、文字、ストロークなど) は、最終的にこのフラット化を通って三角形になっていくよ。

## どうやって動くのか — ステップで見ていこう

### ステップ 1: 曲線が直線で近似できるか？

曲線が **「短くて、ほぼ真っ直ぐ」** だったら、もう直線 1 本で近似していいよね。じゃあ「ほぼ真っ直ぐ」をどうやって判定する？

簡単な方法は、**両端 (p0, p3) を結んだ線 (弦) と、制御点 (p1, p2) との距離** を測ること。距離が小さければ、曲線は弦からあまりはみ出していない、つまり「ほぼ真っ直ぐ」。

`max(d1, d2) ≤ tolerance` (許容誤差) なら、もう直線として返していい。

### ステップ 2: ダメなら半分に分ける (De Casteljau 分割)

「真っ直ぐ判定」がダメだったら、**曲線を真ん中で 2 つに分ける** よ。これがすごく綺麗な方法で、新しい曲線の制御点は **元の制御点の中点をどんどん取っていくだけ** で求まるんだ。これを **De Casteljau の分割アルゴリズム** って呼ぶよ。

中点を 3 段重ねて取った点が、**左の曲線の終点 = 右の曲線の始点** になるよ。新しい制御点もぜんぶ中点で取れる。これだけで「曲線を半分に切る」ことができちゃう。

### ステップ 3: 再帰で繰り返す

半分に切ったあとは、左右それぞれについて **またステップ 1 に戻って判定** するよ。やがて全部の小さな曲線が「真っ直ぐ判定」を満たしたら終わり。

```
flattenCubic(c, tolerance):
  もし弦からの距離 ≤ tolerance なら:
    [p0, p3] を返す
  そうでなければ:
    左半分と右半分に分ける
    左半分を flattenCubic
    右半分を flattenCubic
    つなげて返す
```

### ステップ 4: tolerance で精度を変えられる

`tolerance` (許容誤差) を小さくすると、フラット化の結果は **点が増えて、より曲線にぴったり** になる。大きくすると、**点が減って、カクカク** になる。

## 数学のところ（読み飛ばしOK）

<details>
<summary>De Casteljau の中点公式</summary>

3次ベジェの 4 つの制御点 `p0, p1, p2, p3` を、`t = 0.5` で分割すると、左右の制御点はこうなる:

```
m01    = (p0 + p1) / 2
m12    = (p1 + p2) / 2
m23    = (p2 + p3) / 2
m012   = (m01 + m12) / 2
m123   = (m12 + m23) / 2
m0123  = (m012 + m123) / 2          ← 中央点

左:  [p0, m01, m012, m0123]
右:  [m0123, m123, m23, p3]
```

任意の `t` に対する分割は、 `(a + b) / 2` を `(1−t) a + t b` (線形補間) に置き換えればいい。これが第5章の話だよ。

</details>
