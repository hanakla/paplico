# 第3章: 点が図形の中にあるか調べる (ヒットテスト)

## この章でできるようになること

- 点が多角形の **中** にあるのか、**外** にあるのかを判定できるようになる
- なぜ「光線を伸ばす」と中外が分かるのか、説明できるようになる
- 交差回数の **奇数 / 偶数** が答えのカギになる理由を理解できる

Canvas にぐにゃっとした図形を描いた。点 A は中、点 B は外。**コンピューターはどうやってこの 2 つを区別している** と思う？

## どこで使われている？

ペンや消しゴムで「どの絵に当たった？」を判定するとき、選択ツールで「投げ縄で囲んだ範囲に入っている絵はどれ？」を判定するとき、塗りつぶしツールで「この点を塗ると、どの領域がいっぱいになる？」を判定するとき。**お絵かきソフトはヒットテストだらけ** だよ。

Paplico では、選択ツール (rectangle / lasso) や PathEditTool など、**ほぼすべてのツールがこの判定を使っている** よ。

## どうやって動くのか — ステップで見ていこう

「点 P が多角形の中にいる？」を調べるとっても上手な方法に、**Ray Casting (光線投射法)** っていうのがあるよ。

中にいる点 P は、光線が辺に **1 回** ぶつかる。外にいる点 P' は、ぶつかる回数が **0 回**。

### ステップ 3: 奇数なら中、偶数なら外

これが今日の魔法の一言だよ。**交差回数が奇数なら中、偶数なら外** !

ふしぎだけど、これで本当に判定できるんだ。ザックリ言うと、**辺をまたぐたびに「中／外」がパタンと入れ替わる** 。0 回 (偶数) なら最初と同じ「外」。1 回 (奇数) なら入れ替わって「中」。2 回 (偶数) ならまた入れ替わって元の「外」。

### ステップ 4: 各辺について判定する

辺 (i 番目の点と j 番目の点を結ぶ線) と、点 P から右に伸びる光線が交差するか判定するよ:

```
1. 辺の y の範囲が点 P の y を「またいでる」？
   (片方の頂点が P より上、もう片方が P より下)
2. その辺の上で、点 P と同じ y のところの x 座標は、P の x より右？
3. 両方 YES なら、交差した！
```

これを全部の辺について繰り返して、交差回数を数えるよ。

## 数学のところ（読み飛ばしOK）

<details>
<summary>もう一つのやり方: Winding Number</summary>

Ray Casting とは別に、**Winding Number 法** っていうのもあるよ。

これは「点 P から見て、多角形の頂点が何周まわって帰ってくるか」を数える方法。

- 0 周なら外
- ±1 周なら中
- ±2 周ならもう一周してて、複雑な形 (自己交差あり) のとき意味が変わる

実装はちょっと複雑だけど、**自己交差した多角形 (8 の字みたいなやつ)** に対しても意味のある結果を返すから、PostScript の `nonzero` ルールはこれに基づいているよ。

</details>

## 実装してみる

`pointInPolygon` を書いてみよう。Canvas にたくさんの点をばらまいて、各点を判定するよ。**正しく書けたら、多角形の中の点だけが青く** なるよ。間違っていると、点がぜんぶ同じ色になったり、ヘンな縞模様になったりするよ。
