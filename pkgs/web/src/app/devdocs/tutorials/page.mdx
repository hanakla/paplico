# 幾何学アルゴリズム チュートリアル

このチュートリアルでは、Paplico の中で実際に動いている「幾何学アルゴリズム」を、ガチの初学者でも追えるように、図とコードでひとつずつ学んでいくよ。

## どんなことを学べるの？

絵を描くソフトの中身では、実はたくさんの「数字と図形のお話」が動いている。例えば:

- ぐにゃっと曲がった線（曲線）を、まっすぐな線の集まりに分ける
- 点が図形の中にあるか調べる
- 手書きの線をなめらかに整える
- 4 すみの色をなめらかにつなぐ

こういうことを **「コードを少しずつ書いて、結果を絵で見て」** 確かめていくよ。

## どんな順番で読むといい？

| パート | 章 | 内容 |

| Part 2 | 4〜6 | ベジェ曲線（ぐにゃっとした線）のあつかい方 |
| Part 3 | 7〜9 | 手書きの線をきれいに整える方法 |

## 章一覧

### Part 1 — 座標と境界

これから学ぶ全部の章で出てくる「点の場所の表し方」と「図形の囲み方」を、ここで身につけるよ。

- **第1章: 座標系の話 — Screen / World / NDC**
- **第2章: AABB と図形の囲み方**
- **第3章: ヒットテスト — 点が図形の中にあるか調べる**

### Part 2 — ベジェ曲線

ぐにゃっとした線「ベジェ曲線」を、コンピューターでどうあつかうかを学ぶよ。

- **第4章: ベジェ曲線をまっすぐな線に分ける（フラット化）**
- **第5章: ベジェ曲線を真ん中で 2 つに切る**
- **第6章: ベジェ曲線の上で「一番近い点」を探す**

### Part 3 — 手書き線

ペンでぐにゃぐにゃ書いた線を、コンピューターの中できれいに整える方法を学ぶよ。

- **第7章: ぐにゃぐにゃの線をなめらかにする（スムージング）**
- **第8章: たくさんの点を少ない曲線にまとめる（フィッティング）**
- **第9章: 線を三角形のあつまりにして画面に出す**

### Part 4 — 塗りつぶしと色

図形の中身を塗ったり、色をなめらかにつなげたりする方法を学ぶよ。

- **第10章: 多角形を三角形に分ける（ear clipping）**
- **第11章: ステンシルを使った塗りつぶし**
- **第12章: メッシュグラデーション（4 すみの色をなめらかにつなぐ）**
