# 第9章: ストロークを三角形のあつまりにして画面に出す

## この章でできるようになること

- 1 本の細い線 (中心線) を、**幅を持った帯** に変えて画面に描けるようになる
- **接線ベクトル** と **法線ベクトル** が線の太さを作るカギだと分かる
- WebGPU が三角形しか描けないことを踏まえて、**点列 → 三角形列** の変換が書けるようになる

## まずは絵で見てみよう

ペンで描いた **線** は、ただの「点の並び」 ; 太さがない。これを画面に表示するには、**両側に幅を広げて、リボン状の帯** にしてあげる必要があるよ。

ブラウザの SVG なら `stroke-width` を指定するだけで太くなるけど、**WebGPU は三角形しか描けない**。だから自分で **三角形** に分解する必要があるよ。

## どこで使われている？

ペンで描いた線、ブラシ、消しゴムの軌跡、選択ツールの lasso、レイアウトのガイド線 — **画面に出る線はぜんぶ** 三角形になっているよ。

Paplico の `BrushStrokeRenderer` (テクスチャブラシ) と `path-rendering` (図形ストローク) も、最終的にはこの章でやることをやっているよ。

## どうやって動くのか — ステップで見ていこう

### ステップ 1: 接線ベクトル T を計算

まず、各点 `p_i` での「**進んでいる向き**」を求めるよ。これは前後の点の差分で出せる。

```
T_i = normalize(p_{i+1} − p_{i-1})
```

両端 (i = 0, i = N-1) は **片側の差分** で代用するよ。

### ステップ 2: 法線ベクトル N を作る

接線を **90 度回転** すると、線に **垂直な方向** が手に入る。これを法線って呼ぶよ。

```
N_i = (−T_i.y, T_i.x)   ← 反時計回りに 90 度
```

### ステップ 3: 左右に半幅ずらした 2 点を作る

太さ `w` の半分 (`w/2`) を、法線方向に **両側へ** ずらす。これで各点が **左の点 L_i** と **右の点 R_i** の 2 つになるよ。

```
L_i = p_i + N_i * (w / 2)
R_i = p_i − N_i * (w / 2)
```

### ステップ 4: 隣どうしを 2 つの三角形でつなぐ

連続する 2 点 (i と i+1) について、`L_i, R_i, L_{i+1}, R_{i+1}` の 4 点ができたよ。これを **2 つの三角形** に分けるんだ。

	<text x="180" y="190" textAnchor="middle" fontSize="11" fill="currentColor" fillOpacity="0.7">青三角と赤三角の 2 枚で、1 セグメントの帯ができる</text>
</svg>

頂点の並び方は (時計回り or 反時計回り、向き統一):

```
三角形 1: L_i, R_i, L_{i+1}
三角形 2: R_i, R_{i+1}, L_{i+1}
```

これを **N - 1 セグメント分繰り返す** と、線全体が三角形のあつまりになるよ。WebGPU はこの三角形列を `triangle-list` として描画してくれる。

### ステップ 5: 出力は Float32Array

GPU に渡すため、`{x, y}` のオブジェクトの配列ではなく、**フラットな数値配列** (`Float32Array`) で返すのが約束。各三角形は **3 頂点 × 2 (x, y) = 6 数値**。N-1 セグメント × 2 三角形 = 2(N-1) 三角形 × 6 = **12(N-1)** 個の数値が並ぶよ。

## 数学のところ（読み飛ばしOK）

<details>
<summary>線が曲がるところ (join) のあれこれ</summary>

この章では各点で「単純に法線方向に半幅ずらす」だけだから、**線が急に曲がる場所** で帯の内側がペコっとへこんだり、外側にスキマができたりするよ。これを綺麗にするには:

- **miter join**: 隣接 2 セグメントの法線の **平均** で頂点を作る (尖りが鋭くなりすぎたら制限)
- **bevel join**: 急な曲がりは斜めに切り落とす
- **round join**: 円弧で滑らかにつなぐ

両端の **cap** (端の処理) も同じで、butt / square / round の 3 種類が定番。

Paplico はもっと洗練された tessellator を使っているけど、出発点はこの章でやる「左右に半幅ずらして 2 三角形」だよ。

</details>
