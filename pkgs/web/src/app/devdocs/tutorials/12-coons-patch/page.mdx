# 第12章: メッシュグラデーション (4 隅の色をなめらかにつなぐ)

## この章でできるようになること

- 4 つの色を **四隅に置いた長方形** の中身をなめらかに塗れるようになる
- **双線形補間 (bilinear interpolation)** が「2 段階の lerp」で書けると分かる
- メッシュグラデーションの **基礎部分** (Coons patch の前段) が理解できる

これが **メッシュグラデーション** の基本形。本物の Coons patch はもっと複雑で、辺がベジェ曲線になったりするけど、出発点はこの **「4 隅の色を双線形補間する」** ところ。

## どこで使われている？

- Adobe Illustrator のメッシュグラデーション
- Figma のグラデーション (4 stops の色をブレンド)
- 3D のテクスチャマッピング (頂点ごとの UV/色を補間)

Paplico のメッシュグラデーションも、まずこの bilinear ブレンドを各四角形パッチで計算して、それを compute shader で全ピクセルに展開しているよ。

## どうやって動くのか — ステップで見ていこう

### ステップ 1: 各ピクセルに座標 (u, v) をふる

長方形の左上を `(u=0, v=0)`, 右下を `(u=1, v=1)` とした **正規化された座標** を使うよ。

### ステップ 2: 上の辺と下の辺で先に色を作る

```
top    = lerp(c00, c10, u)   ← 上辺の u 位置の色
bottom = lerp(c01, c11, u)   ← 下辺の u 位置の色
```

### ステップ 3: 縦に補間

```
result = lerp(top, bottom, v)
```

これで終わり！**lerp を 3 回** 呼ぶだけ。これを **双線形補間 (bilinear interpolation)** と呼ぶよ。

### ステップ 4: ImageData に書き込み

各ピクセル `(x, y)` について `u = x / W`, `v = y / H` で色を計算して、Canvas2D の `ImageData` に書き込むよ。300 × 300 なら関数を 90,000 回呼ぶ。Canvas2D で 1 度だけ計算すれば、スクロールしてもなめらか。

## 数学のところ（読み飛ばしOK）

<details>
<summary>Coons patch (本物)</summary>

Coons patch は、双線形補間より一段豊かな曲面補間。4 辺がそれぞれ **3 次ベジェ曲線** になっていて、その内側を以下の式でフィルする:

```
S(u, v) = Lc(u, v) + Ld(u, v) − B(u, v)
```

- `Lc(u, v)` : 上下辺の v 補間 (curve direction lerp)
- `Ld(u, v)` : 左右辺の u 補間
- `B(u, v)`  : 4 隅の双線形補間 (この章のやつ)

つまり、**この章の bilinear が引き算項** として登場する。Paplico の `meshGradient.ts` の `coonsSurfacePoint` がこれを実装しているよ。

</details>
